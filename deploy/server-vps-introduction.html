项目亮点

server-vps 的核心是把分散的 GPU 服务器变成一个好用的共享平台：老师和管理员看得清资源，学生和成员能自助使用，日常运维也更少靠手工操作。

01
多台机器统一管理

不管 GPU 服务器在同一个机房，还是分散在不同网络，只要彼此能按需访问，就可以接入同一个管理节点，在一个网页里集中查看和维护。

02
资源情况一眼看清

在线节点、可用 GPU、运行容器、CPU、内存、磁盘都会汇总展示，管理员不用一台台登录服务器确认谁在用、还剩多少资源。

03
用户自助容器管理

成员在网页里选择镜像、GPU、CPU、内存和端口，就能创建自己的实验环境，还可以直接打开浏览器 Shell 进入容器。

04
更完整的实验环境

server-vps 使用 Incus。它更像轻量级 Linux 主机，适合 SSH 登录、后台服务、长期训练任务和多人隔离环境；同时开销低、启动快，扩展到更多节点也更自然。

05
数据和模型集中管理

个人文件、共享数据集、模型资源、上传下载、预览和同步都放到存储中心，减少“数据到底在哪台机器上”的混乱。

06
方便集中的日常运维

节点接入、端口转发、容器 Shell、Agent 发布和升级都可以在控制台完成，管理员不用为每个小操作反复登录服务器。

适合什么场景

server-vps 更偏向小团队自托管：已有几台 GPU 服务器，希望用较低复杂度做账号、额度、容器、端口和数据的统一管理。

课题组共享 GPU把个人排队和口头协调变成可见资源账本。
实验环境隔离每个任务一个 Incus 容器，降低环境互相污染。
数据集集中维护公共数据集和模型由存储中心统一管理和分发。
轻量运维闭环节点接入、Agent 发布、Shell、同步和升级都放进同一个控制台。
